# TourAgency
Предметная область: «Туристическое агентство» (информационная система бронирования туров).

Назначение системы:

Информационная система «Туристическое агентство» предназначена для подбора, бронирования и управления турами, а также для взаимодействия между клиентами и туристическим агентством. Система предназначена для клиентов (просмотр и бронирование туров) и сотрудников агентства (создание туров, обработка заявок на бронирование). Результат — сокращение времени обработки заявок и прозрачный контроль статусов бронирования.
